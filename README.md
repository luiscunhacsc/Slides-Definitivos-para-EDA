# EDA — Estruturas de Dados e Algoritmos

Portuguese-language lecture slides on data structures and algorithms, organised into 11 lessons. Each lesson is available as a PDF for reading and a PowerPoint presentation for editing or presenting.

## Repository structure

- [`EDA-PDFs/`](EDA-PDFs/): PDF versions of the lecture slides.
- [`EDA-PowerPoints/`](EDA-PowerPoints/): editable PowerPoint (`.pptx`) versions of the same lessons.

## Using the materials

Open a PDF from the table above in a browser or PDF reader. To edit or present a lesson, download its `.pptx` file and open it in Microsoft PowerPoint or a compatible presentation application. No build or installation steps are required for this repository.

When updating a lesson, edit its PowerPoint file and export a matching PDF. Keep the lesson number and filename consistent across both folders so the links above continue to work.
